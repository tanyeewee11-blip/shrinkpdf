Nomor Halaman PDF — Gratis, Tanpa Login

Butuh menambahkan nomor halaman ke PDF — untuk skripsi, laporan, kontrak, atau dokumen kerja — tapi filenya sudah dalam bentuk PDF, bukan Word lagi? Panduan ini menunjukkan cara menambahkan nomor halaman langsung ke file PDF di browser Anda, tanpa login, tanpa upload ke server mana pun, serta cara mengatur posisi, format, dan angka mulai.

Cara Menambahkan Nomor Halaman — Langkah demi Langkah

1

Buka Alat Nomor Halaman

Kunjungi shrinkpdf.fyi/page-numbers.html. Tidak perlu daftar, tidak perlu email.

2

Unggah PDF Anda

Klik Choose PDF File atau seret dan lepas. Alat ini membaca jumlah halaman terlebih dahulu.

3

Pilih Posisi dan Format

Tentukan posisi nomor (bawah tengah, bawah kanan, atas kanan, dll), format angka, dan mulai penomoran dari halaman atau angka berapa.

4

Tambahkan Nomor Halaman dan Unduh

Klik Add Page Numbers. PDF hasil akhir langsung dibuat di browser Anda dan langsung terunduh — tanpa menunggu proses di server.

Memilih Posisi, Format, dan Angka Mulai

Posisi paling umum: bawah tengah atau bawah kanan

Untuk laporan, kontrak, dan skripsi, posisi bawah tengah adalah pilihan paling aman dan paling sering diminta secara format resmi. Bawah kanan juga umum digunakan, terutama supaya nomor halaman mudah terlihat saat menumpuk kertas cetakan lalu membolak-balik cepat mencari halaman tertentu.

Alat ini juga mendukung angka mulai custom — berguna kalau dokumen Anda sebenarnya lanjutan dari file lain (misalnya lampiran yang disambung dari laporan utama), sehingga penomoran bisa diteruskan dari angka terakhir file sebelumnya, bukan mulai dari 1 lagi.

Anda juga bisa melewati halaman di awal — misalnya sampul dan daftar isi tidak diberi nomor, dan angka baru muncul mulai dari halaman isi/BAB I, sesuai format yang biasa diminta kampus atau kantor.

Sudah Beri Nomor di Word, tapi Filenya Sekarang PDF?

Banyak orang mencari cara menambah nomor halaman di Word — masuk menu Insert > Page Number, pilih posisi, selesai. Cara menambahkan halaman di Word ini memang paling umum diajarkan, tapi masalah baru muncul setelah dokumen itu diexport atau dikonversi jadi PDF:

  • Nomor halaman hilang saat export — biasanya karena pengaturan header/footer di Word tidak ikut terbawa dengan benar ke PDF, atau margin PDF berbeda dari margin Word aslinya
  • File PDF-nya sebenarnya hasil scan — bukan diexport dari Word sama sekali, jadi tidak ada nomor halaman dari awal karena filenya berupa gambar hasil scan yang digabung jadi PDF
  • File Word aslinya sudah tidak ada lagi — hanya tersisa PDF-nya (misalnya dikirim orang lain, atau file Word sudah terhapus), jadi tidak bisa kembali ke Word untuk memperbaikinya

Di semua kasus ini, cara paling cepat bukan kembali ke Word, edit ulang, lalu export lagi — tapi langsung menambahkan nomor halaman ke file PDF yang sudah ada, seperti langkah-langkah di atas. Prosesnya lebih cepat dan hasilnya konsisten di semua halaman, tidak tergantung pengaturan margin atau section break di Word yang kadang bikin nomor halaman meleset.

Nomor Halaman untuk Skripsi dan Makalah

Format penomoran skripsi dan makalah di kampus-kampus Indonesia biasanya punya aturan spesifik yang sedikit lebih rumit dari dokumen biasa:

Halaman sampulUmumnya tidak diberi nomor sama sekali
Kata pengantar, daftar isi, abstrakSering diminta pakai angka Romawi kecil (i, ii, iii)
BAB I dan seterusnyaMulai dari angka Arab 1, 2, 3 lagi dari awal
LampiranBiasanya melanjutkan nomor dari BAB terakhir, bukan mulai ulang
Alat ini belum mendukung angka Romawi

Saat ini penomoran hanya mendukung angka Arab berurutan. Kalau kampus Anda mewajibkan format campuran (Romawi untuk halaman awal, Arab untuk BAB), caranya: pisahkan PDF jadi dua bagian menggunakan alat Split — bagian halaman awal dan bagian BAB — beri nomor halaman masing-masing secara terpisah, lalu gabungkan lagi jadi satu file skripsi yang utuh.

Pertanyaan yang Sering Diajukan

Saya sudah beri nomor halaman di Word, tapi hilang setelah jadi PDF. Kenapa? ▼
Biasanya karena nomor halaman di Word ada di header/footer yang terpotong saat export, atau file PDF yang Anda pegang sebenarnya hasil scan ulang (jadi gambar, bukan dokumen asli dari Word). Cara paling cepat: beri nomor halaman langsung di file PDF-nya menggunakan alat ini, tidak perlu bolak-balik ke Word.
Bisakah mulai penomoran bukan dari halaman 1? ▼
Bisa. Anda bisa mengatur angka mulai bebas — misalnya dokumen ini lanjutan dari file lain, jadi bisa diteruskan dari nomor terakhir file sebelumnya.
Halaman sampul bisa dikecualikan dari penomoran? ▼
Bisa. Alat ini mendukung melewati sejumlah halaman di awal — misalnya sampul atau daftar isi dikosongkan, dan nomor halaman baru muncul mulai dari halaman isi.
Untuk skripsi, apakah bisa daftar isi pakai angka Romawi dan bab pakai angka biasa? ▼
Saat ini alat hanya mendukung penomoran angka Arab berurutan, belum angka Romawi. Kalau kampus mewajibkan format i, ii, iii untuk halaman awal (kata pengantar, daftar isi) lalu 1, 2, 3 untuk BAB I dan seterusnya, caranya: pisahkan file jadi dua bagian, beri nomor halaman masing-masing secara terpisah, lalu gabungkan kembali jadi satu file PDF utuh.
Apakah aman memberi nomor halaman pada dokumen rahasia? ▼
Aman. Proses penomoran berlangsung sepenuhnya di browser Anda menggunakan JavaScript — file tidak pernah diunggah ke server mana pun, penting untuk kontrak, laporan keuangan, atau skripsi yang belum boleh dipublikasikan.
File saya sudah ada nomor halaman, lalu saya tambahkan lagi — apa yang terjadi? ▼
Nomor halaman baru akan ditumpuk di atas yang lama, jadi akan terlihat dua angka bertumpuk di posisi yang sama atau berdekatan. Pastikan cek dulu apakah PDF sudah punya nomor halaman sebelum menambahkan lagi lewat alat ini.
