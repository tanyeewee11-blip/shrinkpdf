Fitur Bawaan Excel untuk Impor PDF

Excel punya cara resmi untuk ini

Di Excel untuk Microsoft 365 atau Excel 2019 ke atas, buka menu Data → Get Data → From File → From PDF. Excel akan memindai file PDF-nya pakai Power Query, mendeteksi tabel-tabel yang ada di dalamnya, dan menampilkan pratinjau tiap tabel supaya kamu bisa pilih mana yang mau dimuat ke worksheet. Untuk PDF yang aslinya memang berasal dari spreadsheet atau tabel data yang rapi, cara ini biasanya berhasil dengan sangat baik.

Setelah tabel dimuat, kamu bisa mengedit datanya seperti data Excel biasa — kolom, baris, dan angkanya sudah dalam bentuk sel yang bisa dihitung, bukan sekadar gambar atau teks datar.

Keterbatasan yang Perlu Diketahui

Di mana fitur ini kurang maksimal
  • Tidak tersedia di semua versi: Fitur ini butuh aplikasi desktop Windows atau Mac (365, 2021 ke atas). Excel versi web tidak punya fitur ini, begitu juga beberapa versi Mac yang lebih lama.
  • Rumus tidak ikut terbawa: PDF cuma menyimpan hasil akhir dari sebuah rumus, bukan rumusnya sendiri. Kamu akan dapat angka yang benar, tapi perhitungan di baliknya harus dibuat ulang manual kalau memang dibutuhkan.
  • PDF hasil scan tidak terbaca: Fitur ini membaca tabel berbasis teks, bukan gambar. Dokumen hasil scan butuh OCR dulu, yang tidak disediakan fitur ini.
  • Tabel kompleks atau multi-halaman bisa terpecah: Tabel yang melewati batas halaman atau pakai sel gabungan (merged cell) sering masuk sebagai potongan-potongan terpisah yang harus disatukan ulang manual.

Kalau PDF-nya Hasil Scan

Kalau file PDF kamu hasil scan atau foto dokumen (bukan file digital asli), fitur impor bawaan Excel tidak akan mendeteksi tabel apa pun di dalamnya — karena yang ada cuma gambar, bukan teks yang bisa dibaca komputer. Untuk kasus ini, dibutuhkan software OCR khusus yang bisa mengenali angka dan tabel dari gambar hasil scan terlebih dahulu, seperti ABBYY FineReader, sebelum datanya bisa masuk ke Excel dengan rapi.

Pertanyaan yang Sering Ditanyakan

Apakah Excel bisa langsung membuka file PDF? ▼
Bisa, tapi tidak dengan cara Open biasa. Di Excel untuk Microsoft 365 atau Excel 2019 ke atas, pakai menu Data → Get Data → From File → From PDF. Excel akan memindai file dan menampilkan tabel-tabel yang terdeteksi untuk dipilih mana yang mau dimuat ke worksheet.
Kenapa fitur PDF ke Excel bawaan tidak muncul di Excel saya? ▼
Fitur ini cuma tersedia di aplikasi desktop Windows atau Mac (Microsoft 365, Excel 2019 ke atas). Excel versi web dan beberapa versi Mac yang lebih lama tidak punya fitur ini.
Apakah rumus di PDF akan ikut terbawa ke Excel? ▼
Tidak. PDF cuma menyimpan hasil akhir perhitungan, bukan rumusnya. Kamu akan dapat angka yang benar tapi rumus di baliknya harus dibuat ulang secara manual kalau memang dibutuhkan.
Bagaimana cara ubah PDF hasil scan ke Excel? ▼
Fitur bawaan Excel cuma bisa membaca tabel berbasis teks, bukan gambar. PDF hasil scan perlu diproses dengan software OCR khusus dulu, seperti ABBYY FineReader, sebelum tabelnya bisa diambil dan dimasukkan ke Excel.
