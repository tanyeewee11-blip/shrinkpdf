Kenapa Halaman PDF Bisa Terbalik atau Miring

Ini paling sering terjadi waktu dokumen fisik di-scan atau difoto lalu disimpan sebagai PDF. Kalau kertas dimasukkan terbalik ke mesin scanner, atau HP dipegang dengan orientasi yang salah waktu foto, halaman PDF hasilnya akan ikut terbalik atau miring 90 derajat — meskipun tulisan di kertas aslinya normal-normal saja.

Masalah ini juga sering muncul kalau PDF-nya gabungan dari beberapa dokumen berbeda — misalnya satu halaman hasil scan HP dengan orientasi potret, digabung dengan halaman lain yang di-scan mesin dengan orientasi lanskap. Hasilnya, sebagian halaman normal dan sebagian lagi terbalik dalam satu file yang sama.

Cara Memutar Halaman PDF

Langkah-langkahnya
  1. Buka shrinkpdf.fyi/rotate di browser mana pun — tidak perlu install apa-apa.
  2. Seret file PDF ke halaman, atau klik untuk pilih file dari perangkat kamu.
  3. Pilih arah putaran: 90°, 180°, atau 270°, tergantung seberapa jauh halamannya perlu diputar untuk kembali normal.
  4. Klik download untuk simpan PDF yang sudah diputar ke perangkat kamu.

Semua proses ini jalan langsung di browser kamu — file PDF tidak pernah diunggah ke server mana pun, jadi aman untuk dokumen yang sifatnya pribadi seperti KTP, ijazah, atau kontrak.

Memutar Hanya Sebagian Halaman

Kalau cuma satu atau dua halaman dari file PDF kamu yang terbalik — misalnya di tengah dokumen 20 halaman ada satu halaman hasil scan yang orientasinya salah — kamu tidak perlu memutar semuanya. Tools Rotate PDF ShrinkPDF memungkinkan kamu memilih halaman tertentu saja untuk diputar, sementara halaman lain dibiarkan seperti semula.

Setelah upload file, kamu akan melihat pratinjau tiap halaman. Klik ikon putar di halaman yang mau diputar saja, halaman lainnya tidak akan terpengaruh sama sekali.

Pertanyaan yang Sering Ditanyakan

Kenapa halaman PDF saya terbalik atau miring? ▼
Ini paling sering terjadi karena hasil scan — kalau kertas dimasukkan terbalik atau miring ke mesin scanner atau saat difoto dengan orientasi salah, halaman PDF hasilnya akan ikut terbalik atau miring, meskipun dokumen aslinya normal.
Apakah bisa memutar hanya sebagian halaman saja, bukan semuanya? ▼
Bisa. Tools Rotate PDF ShrinkPDF memungkinkan kamu memilih halaman tertentu untuk diputar sementara halaman lain dibiarkan seperti semula — berguna kalau cuma satu atau dua halaman hasil scan yang orientasinya salah.
Apakah rotate PDF mengurangi kualitas halaman? ▼
Tidak. Memutar halaman PDF hanya mengubah metadata orientasi halaman, bukan menggambar ulang isinya, jadi kualitas teks dan gambar di dalamnya tetap sama persis seperti sebelum diputar.
Apakah file PDF saya diupload ke server saat diputar? ▼
Tidak. Seluruh proses rotate PDF di ShrinkPDF berjalan langsung di browser kamu menggunakan WebAssembly, jadi file tidak pernah meninggalkan perangkat kamu atau diunggah ke server mana pun.
